## 🚀 Featured Project: ProctoSphere
### AI-Powered Anti-Cheat Online Examination Platform

🔗 **Live Demo:** https://proctosphere.in

ProctoSphere is a **multi-tenant SaaS online examination platform** designed to deliver secure, scalable, and AI-assisted remote assessments. It provides enterprise-grade exam management, live proctoring, automated evaluation, and advanced anti-cheat mechanisms for educational institutions.

### ✨ Key Highlights

- 🔹 **Enterprise Backend Architecture**
  - Designed and developed a scalable backend using **Java, Spring MVC, Spring Security, Spring JDBC, MySQL, and Redis**.
  - Implemented modular architecture supporting multiple institutes (tenants), secure exam deployment, and live user monitoring.

- 🔹 **Authentication & Session Security**
  - Built **Role-Based Access Control (RBAC)** for Super Admin, Institute Admin, Proctor, and Student.
  - Implemented **Redis-backed concurrent session management** to enforce strict **single-device login**, preventing unauthorized multiple-device access.

- 🔹 **AI-Powered Remote Proctoring**
  - Integrated **TensorFlow.js**, **MediaPipe**, and **COCO-SSD** for real-time:
    - Face Detection
    - Multiple Person Detection
    - No Face Detection
    - Unauthorized Object Detection (Mobile Phones, Laptops, Books, etc.)

- 🔹 **Advanced Anti-Cheat Engine**
  - Implemented browser lockdown with:
    - Fullscreen Enforcement
    - Tab Switch Detection
    - Window Blur Monitoring
    - Right-Click Blocking
    - Keyboard Shortcut Restrictions
    - Webcam & Screen Permission Validation
    - Automatic Webcam and Screen Evidence Capture on Violations

- 🔹 **Real-Time Examination Engine**
  - Developed:
    - Auto-save Answer System
    - Live Countdown Timer
    - Automatic Submission
    - Heartbeat-based Candidate Tracking
    - Offline Synchronization using Local Storage
    - Cron-based Automatic Exam Scheduling

- 🔹 **Multi-Tenant SaaS Platform**
  - Built isolated workspaces for institutes featuring:
    - Institute Management
    - Batch & Course Management
    - Question Banks
    - Exam Scheduling
    - Capacity Management
    - Live Monitoring Dashboard
    - Student & Proctor Portals

- 🔹 **Reporting & Audit System**
  - Developed:
    - Automatic Result Evaluation
    - Incident Timeline Reports
    - Violation History
    - CSV/PDF Report Export
    - Comprehensive Audit Logs
